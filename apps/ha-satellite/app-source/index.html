Reachy Mini HA Satellite

A Home Assistant voice satellite for the Reachy Mini. Install it from the robot's own dashboard; it needs no shell on the robot and changes no file the robot's image ships.

Nothing is announced to Home Assistant until the robot has been given a name on the application's own settings page, which is served on port 8088 once the application is running.

The source, the documentation and the released wheel this Space installs are at github.com/fx/reachy.
