SPECIFICATION: [Architecture](docs/specs/architecture/index.md)
  SECTION: [REQ-002: One version for the whole repository](#req-002-one-version-for-the-whole-repository)
    TEXT[implication]: Every artifact published from this repository MUST carry the same version
    TEXT[implication]: string, derived from a single repository-wide version.

  SECTION: [REQ-004: Automated leak detection on every change](#req-004-automated-leak-detection-on-every-change)
    TEXT[implication]: Continuous integration MUST reject a change whose diff or commit messages match
    TEXT[implication]: a generic environment-leak pattern — on pull requests and on direct pushes to
    TEXT[implication]: the default branch alike — where the pattern set describes shapes such as
    TEXT[implication]: private IP ranges, internal hostname suffixes, and email addresses rather than
    TEXT[implication]: any specific name.

  SECTION: [REQ-005: Behaviour is testable without hardware](#req-005-behaviour-is-testable-without-hardware)
    TEXT[implementation]: Every workspace member MUST expose its behaviour through interfaces that allow
    TEXT[implementation]: its full test suite to run without a robot, a camera, or a microphone attached.

  SECTION: [REQ-006: Quality gates block merge](#req-006-quality-gates-block-merge)
    TEXT[implication]: Continuous integration MUST run linting, type checking, and the test suite on
    TEXT[implication]: every pull request, and a failure of any of them MUST block merge.

  SECTION: [REQ-007: Vendored third-party code is attributed in place](#req-007-vendored-third-party-code-is-attributed-in-place)
    TEXT[implementation]: Any directory containing code derived from a third-party project MUST carry that
    TEXT[implementation]: project's licence text and a notice recording the upstream project, the files
    TEXT[implementation]: derived from it, and the upstream commit they were taken at.

  SECTION: [REQ-008: Generated contract artifacts cannot drift](#req-008-generated-contract-artifacts-cannot-drift)
    TEXT[implication]: Continuous integration MUST regenerate every published schema and interface
    TEXT[implication]: description from source and fail when the regenerated output differs from the
    TEXT[implication]: committed copy.

  SECTION: [REQ-009: Configuration is validated and self-reporting](#req-009-configuration-is-validated-and-self-reporting)
    TEXT[implementation]: Every component that reads configuration from its environment MUST fail to start
    TEXT[implementation]: when it encounters a variable matching its own prefix that it does not
    TEXT[implementation]: recognise, and MUST emit its fully resolved configuration at startup with every
    TEXT[implementation]: value marked secret replaced by a redacted placeholder.

SPECIFICATION: [Groundstation](docs/specs/groundstation/index.md)
  SECTION: [REQ-022: Capabilities register without transport changes](#req-022-capabilities-register-without-transport-changes)
    TEXT[!MUST,implementation]: Adding a capability MUST NOT require modification to the session layer, the
    TEXT[!MUST,implementation]: transport, or any other capability.

  SECTION: [REQ-023: Model files are present in the image](#req-023-model-files-are-present-in-the-image)
    TEXT[!MUST,implementation,implication]: The service MUST load every model from a file already present in its deployed
    TEXT[!MUST,implementation,implication]: artifact, and MUST NOT fetch model weights over the network at run time.

  SECTION: [REQ-024: Model provenance is recorded and verified](#req-024-model-provenance-is-recorded-and-verified)
    TEXT[!MUST,implementation,implication]: Every model file MUST be pinned by content hash, and the build MUST fail when a
    TEXT[!MUST,implementation,implication]: fetched file's hash does not match the pinned value.

  SECTION: [REQ-025: A failed capability does not take down the service](#req-025-a-failed-capability-does-not-take-down-the-service)
    TEXT[!MUST,implementation]: When a capability fails to initialise, the service MUST continue serving the
    TEXT[!MUST,implementation]: capabilities that initialised successfully.

  SECTION: [REQ-026: Readiness is distinct from liveness](#req-026-readiness-is-distinct-from-liveness)
    TEXT[!MUST,implementation]: The service MUST report itself ready only once every capability it will offer
    TEXT[!MUST,implementation]: has completed its warm-up.

  SECTION: [REQ-027: Inference parallelism is bounded by configuration](#req-027-inference-parallelism-is-bounded-by-configuration)
    TEXT[!MUST,implementation]: The service MUST constrain each model runtime to a configured number of threads
    TEXT[!MUST,implementation]: rather than letting it size itself against the host.

  SECTION: [REQ-028: Work is attributable end to end](#req-028-work-is-attributable-end-to-end)
    TEXT[!MUST,implementation]: Every log line and metric emitted while handling a frame MUST carry the session
    TEXT[!MUST,implementation]: identifier and the frame's sequence number.

  SECTION: [REQ-029: Per-stage timings are measured and exposed](#req-029-per-stage-timings-are-measured-and-exposed)
    TEXT[!MUST,implementation]: The service MUST record the duration of each pipeline stage separately and
    TEXT[!MUST,implementation]: expose those durations as metrics.

  SECTION: [REQ-030: The effective configuration is retrievable at run time](#req-030-the-effective-configuration-is-retrievable-at-run-time)
    TEXT[!MUST,implementation]: The service MUST expose its fully resolved configuration over its own interface
    TEXT[!MUST,implementation]: while running, with every value marked secret replaced by a redacted
    TEXT[!MUST,implementation]: placeholder.

  SECTION: [REQ-031: Images are published for both robot-adjacent architectures](#req-031-images-are-published-for-both-robot-adjacent-architectures)
    TEXT[!MUST,implication]: Every release MUST publish the service image for both 64-bit ARM and 64-bit x86
    TEXT[!MUST,implication]: architectures under the same tag.

SPECIFICATION: [HA Satellite](docs/specs/ha-satellite/index.md)
  SECTION: [REQ-040: The announced device identity is configuration](#req-040-the-announced-device-identity-is-configuration)
    TEXT[!MUST,implementation]: The identity the satellite announces to Home Assistant MUST be read from
    TEXT[!MUST,implementation]: configuration rather than derived from the package name, the host name, or any
    TEXT[!MUST,implementation]: other value that changes when the software is repackaged.

  SECTION: [REQ-041: The application is discoverable by the robot daemon](#req-041-the-application-is-discoverable-by-the-robot-daemon)
    TEXT[!MUST,implementation,implication]: The application MUST advertise itself through the daemon's application entry
    TEXT[!MUST,implementation,implication]: point mechanism so that installing the wheel is sufficient for the daemon to
    TEXT[!MUST,implementation,implication]: find it.

  SECTION: [REQ-042: Decision logic is free of input and output](#req-042-decision-logic-is-free-of-input-and-output)
    TEXT[!MUST,implementation]: The logic that maps voice-pipeline events and detections to motion intents MUST
    TEXT[!MUST,implementation]: be implemented without performing input or output.

  SECTION: [REQ-043: Hardware access goes through the daemon's media layer](#req-043-hardware-access-goes-through-the-daemon-s-media-layer)

  SECTION: [REQ-044: Wake-word detection runs on the robot](#req-044-wake-word-detection-runs-on-the-robot)
    TEXT[!MUST,implementation]: Wake-word detection MUST run locally on the robot, without depending on the
    TEXT[!MUST,implementation]: groundstation or on Home Assistant.

  SECTION: [REQ-045: Speech and intent processing stay in Home Assistant](#req-045-speech-and-intent-processing-stay-in-home-assistant)

    TEXT[!MUST,implementation]: resolution locally.

  SECTION: [REQ-046: Voice pipeline state is expressed through movement](#req-046-voice-pipeline-state-is-expressed-through-movement)

    TEXT[!MUST,implementation]: listening, for processing, and for responding.

  SECTION: [REQ-047: Detection source is selectable](#req-047-detection-source-is-selectable)
    TEXT[!MUST,implementation]: The source of face detections MUST be selectable between the groundstation, the
    TEXT[!MUST,implementation]: robot's own detector, and the groundstation with local fallback.

  SECTION: [REQ-048: The head returns to neutral when tracking data goes stale](#req-048-the-head-returns-to-neutral-when-tracking-data-goes-stale)
    TEXT[!MUST,implementation]: When results stop arriving within the staleness window, the application MUST
    TEXT[!MUST,implementation]: return the head to its neutral position rather than holding its last commanded
    TEXT[!MUST,implementation]: pose.

  SECTION: [REQ-049: Settings are changeable without a shell](#req-049-settings-are-changeable-without-a-shell)
    TEXT[!MUST,implementation]: Every operator-facing setting MUST be changeable through the application's own
    TEXT[!MUST,implementation]: web interface, and MUST be readable there except where the setting is marked
    TEXT[!MUST,implementation]: secret, which is reported as set or unset without its value.

  SECTION: [REQ-050: Shutdown is graceful and leaves the robot safe](#req-050-shutdown-is-graceful-and-leaves-the-robot-safe)
    TEXT[!MUST,implementation]: On receiving a termination signal the application MUST stop commanding movement,
    TEXT[!MUST,implementation]: release the media interface, and exit.

SPECIFICATION: [Robot Link](docs/specs/robot-link/index.md)
  SECTION: [REQ-010: The robot is a client only](#req-010-the-robot-is-a-client-only)
    TEXT[!MUST,implementation]: The robot MUST open the session outbound to the groundstation, and the
    TEXT[!MUST,implementation]: groundstation MUST NOT require any inbound listener on the robot.

  SECTION: [REQ-011: One session carries every exchange](#req-011-one-session-carries-every-exchange)
    TEXT[!MUST,implementation]: All frames, results, and control messages for a running app MUST travel over a
    TEXT[!MUST,implementation]: single session, established once and reused for the lifetime of that session.

  SECTION: [REQ-012: Capabilities are negotiated at session start](#req-012-capabilities-are-negotiated-at-session-start)
    TEXT[!MUST,implementation]: Both sides MUST exchange the set of capabilities they support, each with a
    TEXT[!MUST,implementation]: version, before any capability-specific message is sent.

  SECTION: [REQ-013: An empty result is a valid result](#req-013-an-empty-result-is-a-valid-result)
    TEXT[!MUST,implementation]: A result message carrying no detections MUST be treated as a successful result
    TEXT[!MUST,implementation]: for that frame.

  SECTION: [REQ-014: Results are keyed to the frame that produced them](#req-014-results-are-keyed-to-the-frame-that-produced-them)
    TEXT[!MUST,implementation]: Every frame MUST carry a monotonically increasing sequence number, and every
    TEXT[!MUST,implementation]: result MUST identify the sequence number of the frame it derives from.

  SECTION: [REQ-015: Overload drops frames rather than queueing them](#req-015-overload-drops-frames-rather-than-queueing-them)
    TEXT[!MUST,implementation]: When frames arrive faster than they can be processed, the oldest unprocessed
    TEXT[!MUST,implementation]: frame MUST be discarded in preference to growing the queue or blocking the
    TEXT[!MUST,implementation]: producer.

  SECTION: [REQ-016: Results return the capture timestamp unaltered](#req-016-results-return-the-capture-timestamp-unaltered)
    TEXT[!MUST,implementation]: Every result MUST carry the capture timestamp of the frame it derives from,
    TEXT[!MUST,implementation]: byte-for-byte as the capturing side supplied it, so that the capturing side can
    TEXT[!MUST,implementation]: compute the result's age against the same clock that produced it.

  SECTION: [REQ-017: Stale results stop being acted on](#req-017-stale-results-stop-being-acted-on)
    TEXT[!MUST,implementation]: A consumer MUST stop acting on results once none has arrived within a configured
    TEXT[!MUST,implementation]: staleness window.

  SECTION: [REQ-018: Reconnection is automatic and rate-limited](#req-018-reconnection-is-automatic-and-rate-limited)
    TEXT[!MUST,implementation]: A client MUST re-establish a dropped session automatically, and MUST increase
    TEXT[!MUST,implementation]: the delay between successive failed attempts up to a bound.

  SECTION: [REQ-019: Sessions are authenticated](#req-019-sessions-are-authenticated)
    TEXT[!MUST,implementation]: The groundstation MUST reject a session whose client does not present a valid
    TEXT[!MUST,implementation]: credential.

  SECTION: [REQ-020: The wire format is pinned by shared fixtures](#req-020-the-wire-format-is-pinned-by-shared-fixtures)
    TEXT[!MUST,implementation]: Every message type MUST have a golden fixture in the shared contracts package,
    TEXT[!MUST,implementation]: and both the producing and the consuming implementation MUST be verified against
    TEXT[!MUST,implementation]: that same fixture.

  SECTION: [REQ-021: Detection geometry is resolution-independent](#req-021-detection-geometry-is-resolution-independent)
    TEXT[!MUST,implementation]: Positions in results MUST be expressed in normalised image coordinates rather
    TEXT[!MUST,implementation]: than pixels.
